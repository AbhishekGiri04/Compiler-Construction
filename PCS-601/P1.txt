STUDY OF LEX AND YACC TOOLS

1.  Introduction to LEX

LEX is a software tool used to generate a lexical analyzer, which is the
first phase of a compiler. The lexical analyzer reads the source code
and converts it into a sequence of tokens such as:

Keywords Identifiers Constants Operators Separators

LEX uses regular expressions to define patterns for these tokens and
automatically generates a C program that performs lexical analysis.

LEX is commonly used with YACC, where LEX handles tokenization and YACC
handles parsing.

2.  Working of LEX

The working process of LEX involves the following steps:

-   The programmer writes a LEX program in a file with extension (.l)
-   The LEX tool processes this file
-   It generates a C file named lex.yy.c
-   The C compiler compiles this file
-   An executable lexical analyzer (scanner) is produced

3.  Structure of LEX Program

A LEX program is divided into three sections:

(i) Definition Section Contains header files, macro definitions, and
    declarations. Written between %{ and %}.

(ii) Rules Section Contains patterns (regular expressions) and actions.
     When a pattern matches, the corresponding action is executed.

Example: [0-9]+ printf(“Number”); [a-zA-Z]+ printf(“Word”);

(iii) User Subroutine Section Contains user-defined functions like
      main() and yywrap().

Example: int main() { yylex(); return 0; }

4.  Regular Expressions in LEX

Regular expressions define patterns for matching strings.

a Matches character ‘a’ . Matches any character * Zero or more
occurrences + One or more occurrences ? Zero or one occurrence [a-z]
Lowercase letters [A-Z] Uppercase letters [0-9] Digits ^ Beginning of
line $ End of line

Example: [0-9]+ → Matches one or more digits

5.  Predefined Patterns in LEX

[a-zA-Z] Alphabets [0-9] Digits [a-zA-Z][a-zA-Z0-9]* Identifier [ ]
Whitespace “.*” String constant

6.  Auxiliary Functions in LEX

yylex() → Starts lexical analysis yywrap() → Called at end of input
(returns 1) yytext → Stores matched string yyleng → Length of matched
string

7.  Introduction to YACC

YACC (Yet Another Compiler Compiler) is used to generate a parser.

It checks whether the sequence of tokens follows grammar rules. LEX →
Token generation YACC → Syntax checking

8.  Structure of YACC Program

(i) Declarations Section Defines tokens and variables. Example: %token
    NUMBER

(ii) Rules Section Contains grammar rules. Example: expr : expr ‘+’ expr
     | expr ’*’ expr | NUMBER ;

(iii) Programs Section Contains main function and helper functions.
      Example: int main() { yyparse(); return 0; }

9.  Working of YACC

-   Input tokens are received from LEX
-   YACC checks them against grammar rules
-   If valid → parsing successful
-   If invalid → syntax error generated

10. Conclusion

LEX and YACC are essential tools in compiler design.

LEX → Generates lexical analyzer using regular expressions YACC →
Generates parser using grammar rules

Together, they help in building a complete compiler front-end, making
the process efficient and systematic.
