## 🚀 Getting Started

### 📋 Prerequisites

- 🔧 **Flex/Lex** - Lexical analyzer generator
- 💻 **GCC** - GNU Compiler Collection
- 🖥️ **Unix/Linux/macOS** - Terminal environment
- 📝 **Text Editor** - VS Code, Vim, or any IDE

### 🔧 Installation

#### macOS
```bash
brew install flex
flex --version
```

#### Linux (Ubuntu/Debian)
```bash
sudo apt-get install flex
flex --version
```

### 🏃 Running the Programs

```bash
# Navigate to the lab directory
cd PCS-601

# Compile a Lex program
flex P2.l
gcc lex.yy.c -o P2 -ll

# Run with interactive input
./P2

# Run with input file
./P2 < input.txt
```

### 📝 Program-Specific Commands

```bash
# P6, P7 — reads from Input.txt
flex P6.l && gcc lex.yy.c -o P6 -ll && ./P6

# P8 — removes comments from a C file
flex P8.l && gcc lex.yy.c -o P8 -ll && ./P8 input.c

# P9 — extracts HTML tags
flex P9.l && gcc lex.yy.c -o P9 -ll && ./P9
# (enter: sample.html and tags.txt when prompted)
```

## 📚 Compiler Construction Concepts

### Lexical Analysis Phase

The lexical analyzer (scanner) performs:

1. **Reading Input** - Character stream from source code
2. **Pattern Matching** - Using regular expressions
3. **Token Generation** - Creating token-lexeme pairs
4. **Symbol Table** - Managing identifiers
5. **Error Detection** - Reporting lexical errors

### Token Types

Common token categories:
- Keywords (`if`, `while`, `for`, `return`, etc.)
- Identifiers (variable and function names)
- Operators (`+`, `-`, `*`, `/`, `=`, etc.)
- Literals (numbers, strings, char literals)
- Delimiters (`;`, `{`, `}`, `(`, `)`, etc.)
